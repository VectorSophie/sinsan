# licenses/

Verbatim copies of every third-party license text referenced by
`THIRD_PARTY_NOTICES.md` and `docs/licenses.md`. One file per license,
named after its SPDX identifier (e.g. `GPL-3.0.txt`, `MIT.txt`), fetched
directly from the canonical source (e.g. gnu.org, opensource.org) or copied
verbatim from the upstream project's own LICENSE file when the license is
project-specific (e.g. a custom asset attribution notice).

Do not hand-retype license text from memory — fetch or copy it exactly.
